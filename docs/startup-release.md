## 行为

- 描边用内联 SVG/CSS 连续播放，四秒可见时间与下载字节无关。命中缓存也完整播放；切到后台暂停、返回继续；失败立即停止并提供重试。触控设备的减少动态效果偏好显示静态纹样；电脑端按项目要求默认播放开场动画。
- 下载进度只报告实际下载状态，范围为 0–100%，不驱动描边。纹样约 3.7 秒画完，四秒后保留成图呼吸并等待资源准备；网络或显卡较慢时等待可以超过五秒，不显示虚假的下载百分比。
- 星空生成和桌面星色转换分段让出主线程。遮挡期间不持续绘制完整 3D 场景；描边完成后使用 Three.js 自带异步编译和现有完整合成路径预热，再淡出加载层。
- 开场从原相机距离的 6.5 倍沿小弧线接近，时长约 2.6 秒，终点为原保存视角。拖动、触摸、滚轮、Escape、复位、切换语言、打开工具或进入后台立即取消；复位不重播。介绍卡片在开场后恢复。
- importmap 位于所有模块加载之前。增强脚本最多共享描边等待窗口，慢下载不能继续拖住主体；迟到的增强可使用，但不突然重播开场。运镜按揭幕后的实际时间计时，低帧率不会把两秒多的开场拖长。增强回调统一隔离；初始化失败或运行故障时移除增强 UI、监听器、GPU 资源和临时图片，恢复原控制器与介绍状态。开场期间故障也恢复原视角。
