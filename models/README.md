# Additional blue-and-white porcelain scans

These three distinct Smithsonian collection scans are dedicated to the public domain under CC0 1.0. This museum is an independent presentation and is not endorsed by the Smithsonian. Chinese exhibit names are descriptive translations. Dimensions in the introduction describe the original objects; display size is normalized.

- `covered-vase-192.glb`: Freer Gallery F1980.192a–c, covered baluster vase. [Museum record](https://www.si.edu/object/3d/baluster-vase-one-three-five-piece-garniture-f1980190-194%3Ad8c62634-4ebc-11ea-b77f-2e728ce88125).
- `beaker-vase-193.glb`: Freer Gallery F1980.193a–b, beaker-shaped vase. [Museum record](https://www.si.edu/object/3d/beaker-shaped-vase-five-piece-garniture-f1980190-194%3Ad8c63a70-4ebc-11ea-b77f-2e728ce88125).
- `covered-vase-191.glb`: Freer Gallery F1980.191a–c. The available scan contains the vase body only, without the original cover. The assembled museum dimensions do not describe this partial scan. [Museum record](https://www.si.edu/object/3d/baluster-vase-five-piece-garniture-f1980190-194%3Ad8c6393a-4ebc-11ea-b77f-2e728ce88125).

[CC0 deed](https://creativecommons.org/publicdomain/zero/1.0/) · [Smithsonian Open Access](https://www.si.edu/openaccess) · [Official public file API](https://3d-api.si.edu/api-docs/).

The source URLs, source/output SHA-256 hashes and resource measurements are in `manifest.json`. The original 2048² colour image bytes are retained exactly. Normal maps are resized to 1024² and AO maps to 512². Geometry is simplified from approximately 100,000 triangles to approximately 40,000 using glTF Transform 4.2.1 and Meshoptimizer 0.22.0, with a relative error limit of 0.001. Draco is decoded offline; delivered GLBs require no additional browser decoder. The existing `qinghuaci.glb` is unchanged.

Texture memory figures assume RGBA8 and complete mipmaps. They are estimates rather than measured physical GPU memory; CPU image storage, render targets, geometry and browser memory are additional.
